# Sonoria — site de démonstration

**Sonoria est une entreprise fictive.** Ce site est un support de formation :
il reproduit le site d'un fabricant de panneaux acoustiques, avec ses défauts,
pour servir de terrain d'audit à des apprenants en marketing digital.

Rien ici n'est réel — ni l'entreprise, ni les adresses, ni les prix, ni les avis.
Aucun produit n'est en vente, aucun formulaire n'envoie quoi que ce soit.

Le contenu est généré ; il ne s'édite pas ici.
